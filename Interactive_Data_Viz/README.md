# From Fields to Factories

Interactive dashboard for Malaysia's rubber economy, 2005–2025. Static site: `index.html` plus `bg.jpg`, no build step.

## Embed in Cargo

Paste into a Cargo code block (replace the URL with your GitHub Pages address):

```html
<div style="position:relative;width:100%;aspect-ratio:3053/1804;">
  <iframe src="https://YOUR-USERNAME.github.io/rubber-dashboard/"
          title="From Fields to Factories: Malaysia's rubber economy, 2005–2025"
          style="position:absolute;inset:0;width:100%;height:100%;border:0;"
          loading="lazy"></iframe>
</div>
```
